# AI ANIMATION STUDIO
# UI/UX DESIGN GUIDELINES

**Version:** 1.0.0

## 1. Design Vision

Create a premium, cinematic and professional 3D production interface.

The interface must communicate creativity, precision and advanced technology.

The entire platform must use a consistent Black + Pure Bright Red visual identity.

## 3. Typography

Primary font: Inter.

Secondary font: Manrope.

Typography hierarchy:

- Hero Heading: 64px desktop.
- Page Heading: 36px.
- Section Heading: 28px.
- Card Heading: 18px.
- Body: 14px–16px.
- Caption: 12px.

Use responsive typography.

## 4. Visual Design Principles

- Dark cinematic backgrounds.
- Clean professional layouts.
- Bright red primary actions.
- Minimal visual clutter.
- Consistent spacing.
- Subtle borders.
- Limited red glow effects.
- High-quality 3D previews.
- Clear visual hierarchy.

Avoid excessive gradients, unnecessary animations and decorative effects.

## 10. Interaction Guidelines

Every interactive control must have:

- Default state.
- Hover state.
- Active state.
- Disabled state.
- Loading state.
- Error state where applicable.

## 11. Responsive Design

Desktop:
Full professional editing workspace.

Tablet:
Adaptable panels and collapsible navigation.

Mobile:
Project management, image upload, previews and simplified controls.

Advanced 3D editing should be optimized primarily for desktop.

## 12. Accessibility

- Keyboard navigation.
- Visible focus states.
- Appropriate contrast.
- Accessible labels.
- Tooltips for icon-only controls.
- Clear error messages.

## 13. Animation Guidelines

Use Framer Motion for:

- Page transitions.
- Modal transitions.
- Sidebar transitions.
- Loading indicators.
- Micro-interactions.

Avoid animations that interrupt professional editing workflows.

## 14. Design Acceptance Criteria

All pages must:

- Follow the approved color palette.
- Use consistent typography.
- Share reusable components.
- Support responsive layouts.
- Maintain a consistent interaction system.
- Preserve accessibility requirements.
